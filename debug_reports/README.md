# debug_reports/

Автоматические отчёты о нештатных ситуациях: незнакомые попапы, разлогин
посреди сессии, необработанные ошибки при логине и постинге.

Эта папка **коммитится в git** (не в .gitignore) специально — чтобы отчёты
были доступны в любой момент на любой машине, и их можно было разобрать
вместе с Клодом в новой сессии, не пересылая скриншоты вручную.

## Структура одного отчёта

Каждый инцидент — отдельная папка `<время>_<аккаунт>_<тег>/`, внутри:

- `screenshot.png` — как выглядела страница в момент ошибки
- `page.html` — полный HTML-код страницы на тот момент (по нему можно
  точно писать новые селекторы/правила распознавания)
- `report.md` — читаемая сводка: URL, заголовок, язык страницы, видимые
  кнопки, текст страницы, плюс любые дополнительные данные (например,
  текст и тип исключения, если ошибка была вызвана падением кода)

## Что делать с накопленными отчётами

Периодически просматривай эту папку. По каждому новому типу проблемы —
скидывай путь к папке (или саму папку) в чат, и можно будет:

- дописать новую категорию попапа в `backend/services/dialog_gate.py`
  (`_INSPECT_JS`), если это повторяющийся попап;
- поправить логику логина/постинга, если это баг в коде;
- ничего не делать, если это разовая случайность.

## Дедупликация

Не для всех вызовов — только там, где передаётся `fingerprint`
(например, повторяющийся неизвестный попап при постинге). В таком случае
одинаковый случай фиксируется только один раз, повторные встречи —
просто строка в логе, без нового дубля папки. Ошибки логина и другие
разовые падения кода фиксируются каждый раз без дедупликации.
